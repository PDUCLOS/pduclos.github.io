Public health ML · Team project

Anticipating respiratory emergencies before the wave

Weekly forecast of emergency department visits for acute respiratory infections by French department, based on weather, pollution, the flu index and Google Trends searches. LightGBM model served with Flask, then productionized as a containerized FastAPI API.

The problem, the answer, the proof

Respiratory epidemics overwhelm emergency departments every winter. Anticipating the load one to two weeks ahead makes it possible to adjust staffing and beds.

Training team project (M2i / Jedha): model design, then productionization as an API.

For recruiters · business value
  • Teamwork in a group of 4 on a public-interest topic.
  • First move from notebook to a usable application, then to a containerized service.
For tech teams · what the code proves
  • Environmental features (O3, PM2.5, PM10, NO2…), flu index and search signals; cyclical encoding of the week.
  • Serialized LightGBM + StandardScaler, Flask form prefilled by department / week.
  • Productionization: FastAPI endpoint POST /predict/, Docker image, HTML client.

Step by step

  1. Weekly assembly of environmental, epidemiological and search features by department.
  2. Normalization and training of a LightGBM regression model.
  3. Flask application: the user picks a department and week, adjusts the features and gets the prediction.
  4. Productionization: the same model exposed through a FastAPI API in a Docker container.
