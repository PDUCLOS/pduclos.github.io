PLATFORM · INTEGRATION

From the supplier's file to a comparable price in every entity.

Excel and CSV price lists read as they arrive, automatic matching with the items of each ERP, unit conversion. Anything that cannot be read stays empty, with its reason.

Input formats

Excel or CSV, as it arrives. A PDF is rejected with its reason.

The engine reads the file received from the supplier, with no reformatting: simple, matrix, quantity breaks, several sheets. Whatever it cannot read stays empty, with its reason. A tabular PDF is rejected with an explicit reason, never misread.

Price list integration

One supplier reference. As many items as entities. One matching.

The supplier has a unique key; each entity of the group has its own item code. The engine makes the link: exact match, rule, suggested match, buyer's decision.

Units and conversions

Roll, carton, kilo, m²: every site in the same unit.

Each ERP buys in its own unit. Pondera reads dimensions from the description and applies the declared packaging. Without enough data, it refuses the conversion and says why.
