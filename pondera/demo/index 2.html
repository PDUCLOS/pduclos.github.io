DÉMONSTRATION

Branchez deux fournisseurs. Lisez ce qui sort.

Une démonstration sur un jeu fictif puis, si vous le souhaitez, sur vos données.

Sur devis

Le prix dépend du nombre d'entités, des ERP à raccorder, du mode d'installation et de l'accompagnement. Aucune grille publique.

Comment se passe la démo

  1. D'abord sur un jeu de démonstration fictif : un tarif lu, comparé, chiffré.
  2. Ensuite, si vous le souhaitez, sur deux de vos fournisseurs, chez vous.

La demande n’est pas partie. Corrigez les champs signalés :

    Vos coordonnées

    Champs obligatoires marqués d’un astérisque (*).

    Par exemple : deux ERP différents selon les entités.

    Demande reçue.

    Merci. Nous revenons vers vous pour convenir d’un créneau de démonstration.

    L'outil des directions achats de groupe : tarifs, remises, contrôle et pilotage.
